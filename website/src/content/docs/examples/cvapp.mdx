This example shows a CV editor built with `@nano_kit/store`, `@nano_kit/query`, `@nano_kit/router`, and `@nano_kit/react`.

It is a compact reference for routed application screens, cached async data, derived state, and React components that subscribe to signals.

The **Nanoviews** tab runs the same editor on [Nanoviews](https://nanoviews.js.org), a Direct DOM library built on the Nano Kit core.
